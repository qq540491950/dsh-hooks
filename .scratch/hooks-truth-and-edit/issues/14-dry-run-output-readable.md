# 14: 试运行输出可读

**What to build:** 试运行的结果不再把卡片撑成一大片糊字。现在 hook 的完整 stderr/stdout 被塞进一个没有截断、没有换行保留、没有等宽的行内元素里，而官方模板的输出恰恰是 JSON——最容易命中的场景。本票把结果按字数截断并留"已截断 N 字符"标记、等宽显示、保留换行，可展开查看全文；截断只影响呈现，不改变"通过 / 失败 / 已阻断 / 启动失败"的判定。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 输出超过阈值时截断，并带明确的"已截断 N 字符"标记（不是静默切掉）
- [ ] 等宽字体 + 保留换行 + 可展开看全文
- [ ] 多行/超长输出渲染后卡片高度有上限，不撑破布局（有长度断言）
- [ ] 四种判定文案（通过 / 失败 / 已阻断 / 启动失败）不因截断而改变
