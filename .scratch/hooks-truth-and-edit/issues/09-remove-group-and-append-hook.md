# 09: 删除整组 + 追加到已有匹配范围

**What to build:** 让"同一个匹配范围下多条命令"这个最常见的形态能在页面上完整表达。目前只能一条一条删（最后在文件里留空壳，见 05），也只能新开一组（同一个匹配范围被复制成两个组，文件越用越碎）。本票给「⋯」加"删除整组（N 条）"，复用单条删除的两步确认态；给新建表单加"加到已有的匹配范围里"的选择，追加到该组末尾而不是新开一组；默认行为保持"新开一组"不变。

**Blocked by:** 05, 07

**Status:** ready-for-agent

- [ ] 「⋯」里提供"删除整组（N 条）"，与单条删除共用同一套两步确认交互
- [ ] 删除整组后文件中该组消失，其余组的文件下标仍然正确（后续操作不误伤）
- [ ] 新建表单可选择"加到已有的匹配范围里"，追加到该组末尾
- [ ] 新建表单的默认行为仍是"新开一组"（现有默认语义不变）
- [ ] 两个操作都有断言：定点写只动目标节点、保留性证明通过、未知键保留
- [ ] 断言（渲染层）：能从「⋯」与新建表单产出这两个操作，且确认态不得绕过
