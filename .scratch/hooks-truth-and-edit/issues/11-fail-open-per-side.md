# 11: fail-open 改成按侧回退

**What to build:** 某一侧配置写坏时，另一侧刚改好的内容仍然生效。现在只要任意一侧读不出来，两边的配置就会一起退回 last-good——于是"项目文件坏了"会让"我刚在页面上改好的用户级配置"也不生效，而页面那一侧是新鲜读的（显示的是新内容），页面与实际运行的配置就分叉了。本票把回退改成按侧进行：哪一侧读不出来就只回退那一侧，只有无法判定哪一侧坏时才两侧一起回退；并补一条不变式断言，保证生效配置的每一组都能追到"磁盘当前内容"或"该侧 last-good"。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 只有读不出来的那一侧回退到该侧 last-good，另一侧的磁盘改动照常生效
- [ ] 无法判定哪一侧坏时才两侧一起回退，且这条兜底路径仍有断言
- [ ] 不变式断言：生效配置里的每一组都能追到"磁盘当前内容"或"某侧的 last-good"
- [ ] fail-open 时页面如实标注，且"页面显示的那一份"与"运行时实际使用的那一份"不再分叉（有断言）
- [ ] 删除配置文件仍然是合法的清空，不回退到旧配置
