# 04: 单行紧凑文件保真

**What to build:** 我手写或工具生成的单行 `hooks.json`，被页面编辑一次之后仍然是单行，而不是整个文件被展开重排。现状是风格探测只认"行首空白缩进"，单行文件探不到 → 回退两空格 → 第一次编辑就把整份文件改写成多行，我在编辑器里看到的是"只改了一条命令、整个文件全红了"。本票给风格探测补一档"紧凑（完全没有换行）"，并保持其它已支持形状的逐字节不动点。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 源文件完全没有换行时，一次定点写之后仍然是单行，且除目标字段外逐字段相等
- [ ] tab 缩进、多空格缩进、CRLF、缺结尾换行四种形状仍是逐字节不动点（现有行为不被破坏）
- [ ] 断言覆盖上述五种形状（新增紧凑一档），并做过反向验证
- [ ] 已知残留写进文档：多行但完全无缩进的文件仍会被规范成两空格（可接受、明确记录）
