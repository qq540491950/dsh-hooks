# 15: 写与试运行的时间预算与取消

**What to build:** 宿主一旦卡住，页面不会永久停在"所有按钮都灰"。读请求有超时预算，写请求与试运行没有；而"忙"是整页共享的状态，一个不返回的请求会让每个控件永久禁用，用户只能刷新整个页面。本票给写请求与试运行加上同一套时间预算并支持取消，超时后给出可重试的提示，页面回到可操作状态。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 写请求与试运行都带时间预算，超时后停止等待并给出可重试的提示
- [ ] 在飞请求可取消，或至少不会让页面所有控件永久禁用
- [ ] 一次失败之后页面仍可继续操作，不需要刷新整页
- [ ] 断言（渲染层 + 假请求）：模拟永不 settle 的请求，页面在预算耗尽后离开忙碌态并可再次发起
- [ ] 断言（客户端协议层）：超时被折叠成"永不抛"的结果形状，调用方只需判失败，不需要各自 try/catch
