# 12: 状态证据带时间 + 明确"只记本次进程"

**What to build:** 使用者能分清"刚刚跑过"和"三天前跑过"，也不会把重启后的"未运行"误读成"从来没跑过"。现状是状态点只给 `exit 0 · 12ms`（还在 tooltip 里），没有"多久之前"；台账是纯内存的，重启即空，而文案写的是"没有执行记录"。本票把最近执行的时间以"N 分钟前"上屏，并在页面上用一句话说明状态只覆盖本次进程。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 每行的最近执行时间以相对时间上屏，与退出码/耗时放在同一处
- [ ] 页面上有一句说明状态只记录本次进程；重启后回到"未运行"不再被表述成"从来没跑过"
- [ ] 无记录仍然是灰点「未运行」，不因"没报错"而上色为绿
- [ ] 断言：渲染层对"有记录 / 无记录"两种输入分别检查状态词、颜色类与相对时间文案
